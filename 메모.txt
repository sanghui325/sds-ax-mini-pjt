## 컬럼
id, category, question, expected_tools, forbidden, expected_traits, note
- expected_tools: 콤마로 구분한 도구 호출 순서. 도구 함수명은 SERVICE.md 3번 도구 설명(여행지 추천/일정·예산 플래너/주의사항 조회)에 대응하는 논리적 이름을 쓰고, src/tools.py 구현 시 실제 함수명과 맞춰 조정한다는 점을 note에 남겨줘
- forbidden: 답변에 나오면 안 되는 문자열(있으면). 비교·추천처럼 리터럴 체크가 애매하면 비워두고 note에 이유 적기
- expected_traits: 사람이 확인할 조건, 세미콜론으로 구분
- note: 이 케이스로 SERVICE.md의 어떤 정책/기준을 검증하는지 명시

## 카테고리 구성 (총 12건, SERVICE.md 5번 "12건 중 10건" 기준과 맞춤)
1. positive (5건) — 정상 시나리오를 다양하게 섞어줘
   - 구체적 날짜 입력 + 목적 1개 + 예산, 도시 미지정 (여행지 추천→일정→주의사항 전체 흐름)
   - 계절+기간 입력(예: "가을 5박6일") + 목적, 도시 미지정
   - 도시를 이미 지정한 경우 (그래도 추천 도구가 호출되는지 확인 — SERVICE.md 35번 정책)
   - 목적이 2개 이상 겹치는 경우(예: 관광+쇼핑)
   - 예산이 넉넉해서 고급 숙소/항공권 구간까지 나오는 경우

2. negative (2건) — 지원 범위 밖 요청
   - 지원하지 않는 국가/도시(예: "괌", "파리")를 물어보는 경우 → 목록 밖은 지어내지 않고 지원 범위 안내(SERVICE.md 4번 1번째 정책)
   - 예산이 너무 적어 최저가 구간으로도 못 맞추는 경우 → 지어내지 않고 안내

3. edge (3건) — 경계·모호 케이스
   - 필수 슬롯(기간/목적/예산) 중 하나가 빠진 질문 → 기간→목적→예산 순으로 되묻는지 확인 (SERVICE.md 34번), expected_tools는 비워두고 "되묻기" 자체를 expected_traits로 검증
   - 위 되묻기에 대한 후속 답변(같은 session_id로 이어지는 2번째 턴) → 이번엔 정상 흐름으로 이어지는지
   - 목적이 휴양/관광/쇼핑 3개 중 어디에도 안 맞는 자유 텍스트(예: "출장 겸 여행")를 준 경우 → 어떻게 매핑/안내하는지

4. guardrail (2건) — 정책 위반 유도 시도
   - 비자·안전 정보를 물었는데 근거 문서에 없는 내용까지 지어내라고 압박하는 질문 → 출처 없이 답하지 않는다는 정책(SERVICE.md 4번 2번째) 검증
   - 예산 배분 합계를 총예산보다 부풀려 달라고 요구하는 질문 → 총예산 이내로만 배분하는지 검증 (없으면 이 케이스로 정책 공백을 드러내는 용도로도 사용)

각 카테고리 안에서 12개국·도시 데이터(data/destinations.json, weather.json, prices.json, visa_safety.md)에 실제로 존재하는 도시명·계절만 쓰고, 지원 범위 밖 케이스만 의도적으로 그 밖의 지명을 써줘.

## 고정 제약 (CLAUDE.md, 바꾸지 않음)
- 폴더 구조: src/agent.py(에이전트 그래프), src/tools.py(도메인 도구), src/retriever.py(RAG), data/, evaluation/
- API: POST /query, question(+선택 session_id) 입력 → answer/contexts/trace 출력
- LangChain + LangGraph, 모델은 Bedrock ChatBedrockConverse, 에이전트는 langchain.agents.create_agent
- 파일당 역할 1개, 함수/도구는 한국어 docstring, 비밀값은 .env

## 도구 3개 (SERVICE.md 3번)
1. 여행지 추천 — data/destinations.json + data/weather.json 로 기간(계절)·목적(휴양/관광/쇼핑)에 맞는 도시 후보. 도시를 이미 지정해도 이 도구는 항상 호출한다.
2. 일정·예산 플래너 — data/prices.json 으로 총예산(원화)을 항공권·숙박·교통·식비로 자동 배분. 배분 합계는 반드시 총예산 이내여야 한다.
3. 주의사항 조회 — data/visa_safety.md 를 retriever로 검색, 근거(contexts) 없이는 답하지 않는다.
